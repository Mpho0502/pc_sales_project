# 💻 PC Sales Project

A structured analytics project built on **simulated laptop and PC datasets**, designed to demonstrate practical data exploration, query optimization, and problem‑solving skills.  

This project showcases the ability to **translate business questions into actionable SQL queries**, analyze structured data, and derive meaningful insights in a real‑world‑inspired environment.

---

## 🎯 Project Objectives
- Explore and clean structured datasets representing laptop and PC sales.  
- Apply **T-SQL** queries to answer business‑driven questions.  
- Optimize queries for performance and scalability.  
- Deliver insights into **sales trends, product performance, and customer preferences**.  

---

## 🛠️ Tools & Technologies
- **SQL Server / T-SQL** → Core querying and optimization  
- **Data Modeling** → Structured schema for sales datasets  
- **Business Intelligence Concepts** → Translating business questions into queries  
- **Excel / Power BI (optional)** → Visualizing query outputs  

---

## 📊 Methodology
1. **Data Exploration**  
   - Understand dataset structure (products, sales, customers).  
   - Identify key attributes for analysis.  

2. **Query Development**  
   - Write SQL queries to answer business questions (e.g., *Which product category generates the most revenue?*).  
   - Apply filtering, grouping, and joins to combine datasets.  

3. **Optimization**  
   - Use indexing and query tuning techniques to improve performance.  

4. **Insights & Reporting**  
   - Translate raw query results into **business insights**.  
   - Highlight trends in product sales, discounts, and profitability.  

---

## 📂 Example Business Questions
- Which **PC brand** has the highest sales volume?  
- What is the **average discount** applied across product categories?  
- Which **month or quarter** shows peak sales activity?  
- How do **laptop vs. desktop sales** compare in terms of revenue?
